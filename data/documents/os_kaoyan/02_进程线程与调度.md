# 操作系统考研讲义 02：进程、线程与处理机调度

## 进程与线程的区别
程序是静态的指令集合，进程是程序的一次执行活动。进程控制块 PCB 记录标识、状态和调度等管理信息。线程拥有独立的程序计数器、寄存器上下文和栈，同一进程内的线程共享地址空间、代码、数据及部分系统资源。通常将进程看作资源分配单位，将内核可调度的线程看作处理机调度单位。

## 进程状态转换
三种基本状态是就绪、运行、阻塞。调度使就绪进程进入运行态；时间片用完等抢占事件可以使运行进程回到就绪态；等待 I/O 或同步事件使运行进程阻塞；事件完成使阻塞进程回到就绪态。阻塞进程不能在事件尚未满足时仅因获得 CPU 就继续执行。

## 用户级线程与内核级线程
用户级线程由用户空间线程库管理，内核级线程由内核管理。多对一模型中，一个阻塞内核执行实体可能影响其映射的多个用户线程，而且不能借此在多个核上同时执行；一对一模型则把用户线程映射到不同内核线程。讨论线程阻塞与并行能力时必须说明映射模型。

## 调度指标与公式
设到达时刻为 A，完成时刻为 C，总 CPU 服务时间为 S：周转时间 T=C-A，带权周转时间 W=T/S。响应时间是首次获得响应或首次运行的时刻与到达时刻之差，要按题目定义使用。没有 I/O、只有一次 CPU 服务的简化题中，等待时间为 T-S；含 I/O 时不能直接把全部非 CPU 时间都算作就绪队列等待。

## 常见调度算法
- FCFS：先来先服务，长任务可能让后到短任务等待很久。
- SJF：非抢占地选择当前就绪队列中服务时间最短的任务。
- SRTF：选择剩余服务时间最短的任务，可以抢占。
- RR：按时间片轮转；片太大趋近 FCFS，片太小会增加切换开销。
- 优先级调度：按题目规定的优先级方向选择；长期等待可用老化缓解。
- HRRN：非抢占地选响应比最大的作业，响应比=(等待时间+服务时间)/服务时间。

## 自编调度计算题
单 CPU、无 I/O、忽略切换开销。P1、P2、P3 的到达时间分别为 0、1、2，服务时间分别为 6、2、1。

FCFS：P1 运行 0–6，P2 运行 6–8，P3 运行 8–9。按 P1、P2、P3 顺序，周转时间是 6、7、7，平均为 20/3。

非抢占 SJF：P1 运行 0–6；到 6 时 P2、P3 都已就绪，先执行 P3 直到 7，再执行 P2 直到 9。周转时间为 6、8、5，平均为 19/3。不能让尚未到达的任务在时刻 0 参加选择。

SRTF 约定剩余时间相等时不抢占：执行次序为 P1 0–1、P2 1–3、P3 3–4、P1 4–9。周转时间为 9、2、2，平均为 13/3。
