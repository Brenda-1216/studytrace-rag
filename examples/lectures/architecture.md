# 计算机组成原理：存储与流水线

## Cache
Cache 利用程序访问的时间局部性和空间局部性，缓存主存中的一部分数据，以缩小 CPU 与主存之间的速度差距。
时间局部性表示刚被访问的数据可能很快再次被访问；空间局部性表示某个地址附近的数据也可能很快被访问。
直接映射中，每个主存块只能放入一个固定 Cache 行；全相联映射中，可放入任意 Cache 行；组相联映射中，可放入某个固定组中的任意行。

## 指令流水线
指令流水线将指令处理分为多个阶段，让不同指令在不同阶段重叠执行，从而提高吞吐率。
流水线冒险包括结构冒险、数据冒险和控制冒险。数据旁路可以缓解部分数据冒险，分支预测可以降低控制冒险的影响。
